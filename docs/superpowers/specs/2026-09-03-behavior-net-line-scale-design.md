# 行为面板 · 净差线独立比例尺 + 全图配净差线 + 30 日回溯（设计稿）

- 日期：2026-09-03　状态：已实施　发起：用户（09-03 反馈"比例尺还是太小，净差线看不出变化"）
- 关联：docs/specs/2026-07-22-behavior-net-sum-layering-design.md（第三幅分层口径）、
  docs/superpowers/plans/2026-07-29-behavior-panel-beijing-day.md（北京日口径）

## 1. 背景与问题

行为面板每幅图的净差线和涨跌柱共用同一条 Y 轴。柱子是"涨 +N / 跌 −N"上下发散，
轴域被撑到 ±max(涨, 跌)（30 天里常见 ±20 段以上），而净差 = 涨 − 跌 通常只在 ±几段
之间波动，被压成一条几乎水平的线。此前 6ef5994 放大过图高（120/100/150 → 180/160/220），
用户 09-03 反馈"还是太小"——问题在**比例尺**（线用了柱的尺子），不在像素高度。

另外三处缺口：第二幅（强度 0.5/0.8 档）、第三幅（净幅Σ）、第七幅（情绪占比）没有净差线；
回溯窗口固定 14 天，看不到一个月级别的趋势。

## 2. 目标 / 非目标

**目标**
1. 净差线用自己的比例尺（右侧副 Y 轴）撑满图高，肉眼可见起伏。
2. 每幅有涨/跌方向的图都配一条净差线。
3. 回溯 30 个北京日。

**非目标**（明确不做）
- 不改后端口径与接口：`/behavior/daily` 已支持 `days ≤ 90`，读层现算，无需改动。
- 不动第四幅"构成堆叠"（新闻驱动/纯共振/情绪·技术面三类计数，没有涨跌方向，"净差"无定义）。
- 不改配色、图高、段检测与档位阈值。

## 3. 方案

### 3.1 双 Y 轴 + 对称值域

- 左轴 = 柱（段数或 %），右轴 = 净差线，各自独立取值域。
- 两轴都取**对称值域** `[−m, +m]`，m = 本窗口内该轴数据的最大绝对值向上取整
  （段数取到偶数，百分比取到 1/1.5/2/3/4/5/6/8/10 × 10ᵏ 的"整刻度"）。
  对称的目的是让两条零线重合：否则线在"零上"、柱在"零下"会读错方向。
  代价：柱侧涨跌不对称时一侧留白，可接受。
- 右轴刻度着净差线的颜色（`--text`），提示"右边这把尺子是给线看的"。
  与 `Charts.tsx` 里副轴用线色的既有做法一致。
- 刻度显式给 ±m、±m/2、0 五个：recharts 对固定值域自己挑刻度时从下限按"整步"递增
  （实测 [−15, 15] 出 −15/−7/1/9），零线没有标签、上下不对称，读数别扭。
- 备选（已否）：(a) 净差线另开一幅小图——多占一倍纵向空间，且线与柱脱离对照；
  (b) 保留单轴、把线乘一个放大倍数——刻度失真，读数要心算还原。

### 3.2 各图净差定义（前端 `buildDailyRows` 现算，全部由既有字段推得）

| 图 | 净差 | 字段 | 状态 |
|---|---|---|---|
| ① 0.3 档段数 | 涨 − 跌 | `net` | 已有，改读右轴 |
| ② 强度 0.5/0.8 档 | (0.5涨 + 0.8涨) − (0.5跌 + 0.8跌) | `strongNet` | 新增 |
| ③ 涨/跌段净幅Σ | 涨Σ − \|跌Σ\| | `sumNet` | 新增 |
| ④ 构成堆叠 | — | — | 不适用 |
| ⑤ 情绪·技术面段数 | 个数差 | `sentNetCount` | 已有，改读右轴 |
| ⑥ 情绪·技术面净幅Σ | 净幅差 | `sentNetAmp` | 已有，改读右轴 |
| ⑦ 情绪·技术面占比 | 涨占比 − 跌占比（分母 < 5 → 空，线断开） | `sentRatioNet` | 新增 |

档位计数按段的 `tier_max` 归桶，互斥（一段只计一次），所以 ② 的"强段"= 0.5 档 + 0.8 档，
与第三幅"强段"、情绪拆分的分母是同一批段，可互相对账。

### 3.3 30 日回溯

- 前端 `days: 14 → 30`，标题同步；接口上限 90。
- 读层是现算：30 天 = 60 次按日聚合查询（`aggregate_day` + `day_direction_extras`），
  标注页全量回溯远大于此，线上可接受。

## 6. 追加（同日第二轮）：新闻+共振净幅差 与 宏观贡献占比

用户提法："拿当日所有 0.5/0.8 档的（净幅）差减去仅情绪档的差，就是新闻和共振带来的净幅；
这个净幅占总净幅高，就说明是宏观主导的行情，比例画在同一张图上。"

### 6.1 口径

- 强段净幅差 = 强段涨Σ − |强段跌Σ|（`up_net_sum_strong` / `down_net_sum_strong`，只含 tier_idx ≥ 1 的段）。
- 情绪净幅差 = 情绪涨Σ − |情绪跌Σ|（第六幅已有的 `sentNetAmp`；情绪段是强段的子集，同一批段、同一口径）。
- **宏观净幅差** = 强段净幅差 − 情绪净幅差 = 新闻驱动 + 纯共振（+ 当日尚未定案的强段，仅盘中）的净幅差。
- 弱段净幅差 = 总净幅差 − 强段净幅差（0.3 档碎步）。恒等式：**总 = 宏观 + 情绪 + 弱段**，悬浮提示逐项列出便于对账。
- **宏观贡献占比** = 宏观净幅差 ÷ 当日总净幅差 × 100。分母取第三幅的"净幅差"（含弱段），
  因为要回答的是"全天行情谁主导"，弱段阴跌也是行情的一部分。
  - |总净幅差| < 0.5%（`MACRO_SHARE_FLOOR`）视为横盘，占比留空、线断开。
  - 占比是带符号的贡献率：负值 = 宏观与全日方向相反（如 08-31：宏观 +0.83、弱段 −1.36、全日 −0.53 → −157%）；
    超 100% = 宏观推力大于全日净幅，其余被情绪/弱段抵消。与财务上的差异贡献分析同一读法。
  - 作图钳位到 ±200%（`MACRO_SHARE_CAP`）防极端值撑爆轴；悬浮提示给原值。
- 读法：占比 > 50% 读作宏观主导（图上画 50% 虚线）。线上 30 日实测：08-24 94%、08-27 99%、08-28 99%（宏观主导的涨/跌），
  08-19～08-21 情绪段密集期只有 16%～41%。

### 6.2 呈现

- 新增第八幅，放在"情绪净幅Σ"之后：柱 = 宏观净幅差（涨青/跌玫红，读左轴 %），蓝线 = 宏观贡献占比（右轴 %，新闻蓝刻度）。
- 两轴仍各自对称、零线重合（沿用 §3.1）。
- 前端纯函数现算，后端不动。字段：`strongAmpNet` / `macroAmpNet` / `weakAmpNet` / `macroShare` / `macroSharePlot`。
