# 缓冲区并入新闻快讯 设计

日期:2026-08-06。来源:用户拍板"缓冲区能否和新闻快讯板块合并"→ 选定方案"并过去 + 加紧凑行模式"。
前置:docs/specs/2026-08-05-event-pool-ui-redesign-design.md(事件池改版已上线)。

## 0. 现状与两个坑

| | 新闻快讯(NewsPage) | 缓冲区(事件池页签) |
|---|---|---|
| 数据 | `/api/news`:源/分数/回溯/金十标记/关键词,中英双栏卡片,分页 50 | `/api/research/buffer`:一句派生查询 |
| 口径 | 只按分数与源过滤 | **过闸**(≥6 或未评分 或命中活跃事件关键词)+ **非黑名单** + **无未摘下挂接** |
| 用途 | 只读浏览 | 干活:勾选 → 立事件 / 挂到事件 |

合并前必须处理的两处不一致(实证自 services/news_service.py):

1. **未评分新闻在新闻快讯里根本看不到**。`passes_default_importance_filter` 把 NULL 当 0 分,而分数下拉最小值是 1+,所以未评分新闻除非是金十重要标记否则一律被滤掉;缓冲区却**故意包含**它们(评分失败≠不重要)。→ 分数下拉新增"不限(含未评分)",后端允许 `min_llm_importance=0` 表示不设门槛。
2. **新闻快讯只显示 config 里 enabled 的源**,缓冲区不看这个。investinglive 已于 2026-08-06 下线,所以并过去之后,它的存量新闻不再出现在缓冲视图里(存量行仍在库、仍在事件时间轴里显示)。这是可接受的副作用,不额外开口子。

## 1. 后端

### 1.1 `/api/news` 新增两项(默认值 = 现状,不影响老调用)

| 参数 | 语义 |
|---|---|
| `buffer_only: bool = False` | 只看缓冲区口径的新闻(过闸 + 非黑名单 + 无未摘下挂接) |
| `min_llm_importance = 0` | 0 = 不限(含未评分);≥1 时行为不变。下限由 1 放宽到 0 |

- **口径唯一来源**:`services/event_pool.py` 抽出 `buffer_predicate(session) -> Callable[[NewsItem], bool]`,`buffer_news()` 与 `/api/news` 都用它,杜绝两处定义漂移。
- 执行顺序:SQL 取候选(时间窗/源/关键词,≤5000)→ 分数过滤 → 金十标记过滤 → **buffer 谓词** → 计数分页。谓词需要的"已挂 news_id 集合"与"活跃事件关键词"每次调用查一次,不进循环。
- `/api/research/buffer` 保留不动(程序化入口 + 既有测试),UI 不再调用。

### 1.2 不动

挂接/闸门/黑名单逻辑、`EVENT_LINK_MIN_IMPORTANCE`、事件池其它接口、数据库 schema。

## 2. 前端

### 2.1 新闻快讯(NewsPage)

- 工具栏新增:
  - **视图**:卡片(默认,现状中英双栏)/ 紧凑(单列单行,密度对齐事件池行);
  - **仅看未挂事件** 复选框(= 缓冲区口径);
  - 分数下拉首项加"不限(含未评分)"(value=0)。
- **紧凑模式**:单列,一行 = `[勾选框] 时间 · 来源 · 分数 · 方向 · 标题`,复用事件池那套行网格类(同一套 CSS,不复制)。勾选框仅在"仅看未挂事件"开启时出现。
- **操作条**(勾选后出现,从原缓冲区页签整体搬来):已选 N 条 → 事件名 / 关键词 / AI 建议 / 立事件 / 挂到事件…。成功后清空选择并刷新列表与事件缓存。
- 选择集跨翻页保留(方便跨页凑一个事件);切换"仅看未挂事件"或视图时不清空。
- 卡片模式下勾选与操作条不出现(卡片布局塞勾选框会挤),要立案就切紧凑。

### 2.2 宏观事件池(ResearchPage)

- 删除"缓冲区"页签与 `BufferTab` 组件;页签只剩 事件 / 旧事重提。
- 进行中面板头部加一个跳转:"去新闻快讯挑证据 →"(链接 `/news`),避免入口丢失。

## 3. 测试(先写后实现)

- `tests/test_api.py` / 新增 `tests/test_news_buffer_filter.py`:
  - `buffer_only=true` 排除已挂事件的新闻、排除黑名单、排除未过闸(低分且不命中关键词);保留未评分;
  - `min_llm_importance=0` 时未评分新闻可见,`=6` 时不可见;
  - 两者组合的计数与分页 `total` 一致。
- `tests/test_event_pool.py`:`buffer_predicate` 与 `buffer_news` 结果一致(同源保证)。
- 前端 `NewsPage.test.tsx`(若无则新建):紧凑行的纯函数(分数文案/勾选可见性)。
- 全量 pytest + vitest + tsc 绿。

## 4. 验收

1. 新闻快讯切"紧凑 + 仅看未挂事件",列表与旧缓冲区条数口径一致(抽查同一时间窗)。
2. 分数选"不限(含未评分)"能看到"未评分"行;选 6+ 时它们消失。
3. 勾两条 → 立事件成功 → 该两条从列表消失(已挂),事件池里出现新事件。
4. 事件池不再有缓冲区页签,头部跳转可达新闻快讯。
5. 老用法不回归:不带新参数的 `/api/news` 行为与改前一致。

## 5. 不做

- 卡片模式下的勾选/立案(要立案就切紧凑)。
- 把"仅看未挂事件"做成独立路由或保留旧缓冲区页签作兼容(一次切干净)。
- 给 investinglive 等已下线源开例外通道。
