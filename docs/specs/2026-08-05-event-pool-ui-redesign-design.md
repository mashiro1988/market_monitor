# 事件池页面改版(研究页 UI/UX)设计

日期:2026-08-05。来源:用户对研究页的三段语音反馈(命名/顶栏/卡片化/详情筛选分页/缓冲区排版)+ 三项拍板决定。
基线:docs/specs/news-research-phase1-event-pool.md(下称"一期 spec")已上线的研究页。本文只改工作台呈现与查询接口,**不动挂接/闸门/黑名单等任何计算逻辑与校准参数**。

## 0. 已拍板决定

| 议题 | 决定 |
|------|------|
| 页面命名 | 侧边栏与页头统一叫**事件池**;副标题("宏观事件池:人立案、机器挂证据、价格来验证")删除 |
| 顶栏两率 | **仅保留挂接率**(带悬停提示(tooltip,=鼠标停上去浮出的说明文字)解释口径);纠错率从页面移除——后端 /stats 照算照返,验收期由用户让 Claude 拉库查看,一期 spec §13 的切换标准不变 |
| 卡片统计 | 今日 +N 与**昨日 +N**(北京日,同现有 today_new 口径) |

## 1. 顶栏

- `PageHeader title="事件池"`,无 subtitle。
- 顶栏一行:挂接率 X%(tooltip 沿用现文案)· 回扫待处理 N 条(N>0 时显示)· 右侧三个页签(事件/缓冲区/旧事重提)。
- 纠错率不再渲染;`ResearchStats` schema 与 `daily_stats()` 不动。

## 2. 事件卡片区(进行中)

针对反馈:竖排单行列表在事件多了以后没法扩展;#号不连续看着像乱序;"徽章"在行尾导致"今日+N"不对齐。

- 进行中事件改**卡片网格**(豆腐块):`repeat(auto-fill, minmax(240px, 1fr))`,宽屏自然 3-4 列。
- **排序保持一期 spec §9.1 的"最新证据时间倒序"**(最近活跃在前);卡片上直接显示最新证据时间,让排序自解释。#号仅是立案编号,不承担排序含义。
- 卡片三行,chip 顺序固定保证跨卡片对齐:
  1. `#id 名称`(超长截断,title 悬停出全名);
  2. 统计行:`徽章 N`(仅 N>0 显示,固定放首位)→ `今日 +N` → `昨日 +N`(这两个恒显示,0 时灰色);
  3. 辅助行:`证据 N · 最新 MM-DD HH:MM`;`days_since_last ≥ 3` 时追加灰 chip "N 天无新证据"。
- 点卡片选中(accent 边框),下方渲染详情区——保持用户认可的大原则:**上面是事件池标题区,下面是展开区**。再点取消选中。
- 搜索框(搜事件名/关键词,含已关闭)保留在卡片区上方;已关闭事件维持折叠列表(不卡片化)。

## 3. 事件详情区(时间轴工作台)

- **头部瘦身**:`#id 名称` + 状态 chip + "回扫进行中(剩 N 条)" chip + 一个**"管理"下拉菜单**,收纳五个低频操作:改名 / 关键词 / 关闭(或重开)/ 合并到… / 深回扫。各操作交互与现状一致(prompt/confirm);深回扫确认文案注明"全池重扫,按每 5 分钟 200 条排队消化"。
- **筛选栏**(新增,针对"592 条里快速捞重要证据"):
  - 时间窗:全部(默认)/ 近 1 天 / 近 3 天 / 近 7 天(滚动窗口,按新闻时间);
  - 分数 ≥:不限 / 6 / 7 / 8(设了则排除未评分);
  - 10min 波动 ≥:不限 / 0.1% / 0.2% / 0.3% / 0.5%(设了则只留观测状态 ok 且 |net_pct| 达标的行);
  - 分页:每页 50 条,显示"第 x/y 页"与前后翻页。
- **大波动高亮**:|net_pct| ≥ 0.3% 的观测 chip 用醒目样式(前端常量 `OBS_HOT_PCT = 0.3`,纯显示,不进配置)。观测标的沿用 `EVENT_OBS_SYMBOLS`(现为 BTC/USDT),不动。
- **行内容**:时间 · 来源 · **分数(新增;llm_importance 为空显示灰字"未评分")** · 方向标 · 观测 chip · driver 徽章 · 评分失手徽章 · auto 标记 · 标题 · 行尾**只留一个"改归属…"下拉**。
- **改归属下拉新增"摘回缓冲区"项**(替代原独立"摘下"按钮):选中后 prompt 摘下原因(默认"手动摘回",可改可空,取消则中止),走现有 `PATCH /research/links/{id} {detached: true, detach_reason}`。摘回后该新闻按缓冲区定义(过闸+无未摘下挂接)自然回到缓冲区。

## 4. 缓冲区页签

针对反馈:标题带黑话、筛选散落、行排版散架("—分"被读成"一分")。

- 标题就叫**缓冲区**,删除"(过闸未挂)"。
- 筛选收成一条紧凑栏:时间窗(近 1 / 3(默认)/ 7 天)· 最低分(不限 / ≥6 / ≥7 / ≥8)· **标题关键词搜索框(接后端已有 q 参数,UI 此前一直没接)**· 仅看已确认 driver 复选框。
- 行布局:`勾选框(13px) · 时间 · 来源 · 分数 · 标题`,专用网格列,单行对齐;分数为空显示灰字**"未评分"**,不再出现"—分"。
- 勾选后的操作条(已选 N 条 → 立事件 / AI 建议 / 挂到事件…)功能不变,仅样式随新行风格收紧。

## 5. 排版散架的根修(CSS)

根源:研究页三处列表都借用了行为面板的 `.evidence-row`(固定 4 列网格),元素数对不上导致折行错位。

- styles.css 新增研究页专用样式:卡片网格/卡片、筛选栏、时间轴行、缓冲区行(网格列宽按 §3/§4 定义);研究页不再使用 `.evidence-row`。
- 旧事重提页签行改用同一套新行样式(功能不动)。
- `.evidence-row` 本体与行为面板不动。

## 6. 后端改动(仅查询侧,零 schema 迁移)

### 6.1 GET /api/research/events

- `list_events()` 新增派生字段 `yesterday_new`(昨日北京日,`link.created_at` 计数,与 today_new 同口径);`ResearchEventItem` 加同名字段(默认 0,向后兼容)。

### 6.2 GET /api/research/events/{id}/timeline

新增可选 query 参数,全部不传时行为与现状一致(除了默认分页):

| 参数 | 语义 |
|------|------|
| `days: int|None` | 滚动时间窗(1/3/7),按新闻 timestamp 过滤;None=全量 |
| `min_score: int|None` | `llm_importance >= min_score`,设了则排除未评分 |
| `min_abs_move: float|None` | 观测 ok 且 `abs(net_pct) >= min_abs_move`;pending/no_data 一律排除 |
| `page: int = 1` / `page_size: int = 50` | 筛选后分页,page_size 上限 200 |

- 执行顺序:天数窗过滤 → 快照批量查询限定在窗内新闻的时间范围(窗口小时查询也小)→ 现算观测 → 分数/波动过滤 → 分页。
- `TimelineResponse` 新增 `total`(筛后总数)/ `page` / `page_size`(均带默认值,向后兼容);`pending_relink` 口径不变。

### 6.3 不动清单

- `/research/buffer`(q 参数已存在)、`/research/stats`、WeCom 日报、挂接调用、闸门线、黑名单、`EVENT_LINK_MIN_IMPORTANCE`、排序规则、数据库 schema:全部不动。

## 9. 验收清单(上线后逐条过)

1. 侧边栏与页头均显示"事件池",无副标题;顶栏无纠错率,挂接率 tooltip 正常。
2. 宽屏下进行中事件呈 3-4 列卡片;chip 顺序固定对齐;点卡片下方展开详情,再点收起。
3. #1(592 条)默认只加载第 1 页 50 条;"近 1 天 + 分数≥8 + 波动≥0.3%"组合筛选生效,命中行观测 chip 高亮。
4. 时间轴每行可见分数;未评分显示灰字"未评分"。
5. 改归属下拉含"摘回缓冲区",执行后该新闻出现在缓冲区页签(时间窗内)。
6. 缓冲区无"过闸未挂"字样;筛选一行紧凑;行单行对齐;不再出现"—分"。
7. 标注页跳转研究页的既有链接(EventAttach)不受路由/命名调整影响。

## 10. 不做(YAGNI)

- 卡片区自身的分页/折叠(6 个事件远未到量;将来事件多了再议)。
- 已关闭事件卡片化、时间轴导出、波动阈值可配置化。
- WeCom 日报加两率(用户未选该方案)。
- 深回扫改为按事件粒度(仍是全池行为,仅在确认文案中写明)。
